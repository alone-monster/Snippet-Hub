# ✨ Animated Login & Registration Form

Welcome to the first project of my coding series! This is a beautiful, modern, and fully responsive **Login and Registration Form** built with smooth sliding animations using HTML, CSS, and vanilla JavaScript.

---

## 🚀 Features
* **Dual Layout:** Seamlessly switch between Login and Register panels.
* **Smooth Animations:** Premium sliding and toggle effects powered by CSS transitions.
* **Responsive Design:** Optimized for desktops, tablets, and mobile devices.
* **Social OAuth Icons:** Includes clean integration placeholders for Google, Facebook, GitHub, and LinkedIn icons using Boxicons.

---

## 📂 Files Included
This folder contains the following core files:
1. `index47.html` — The structural layout of the forms.
2. `style47.css` — The styling, custom Google Font (Poppins), sliding animations, and media queries.
3. `script47.js` — The logic to toggle the active state between forms.

---

## 🛠️ How to Use

### 1. Copy the Code
You can directly view and copy the code from the files above to use in your own projects:
* Open `index47.html` ➔ Copy the markup.
* Open `style47.css` ➔ Copy the styles.
* Open `script47.js` ➔ Copy the script.

### 2. Run Locally
If you download these files, make sure they are all in the **same folder** on your device. Simply double-click `index47.html` to open it in your browser!

> ⚠️ **Note:** Internet connection is required to load the external font (Poppins) and the icons (Boxicons).
